# Skeleton — Public Portfolio Release Status

**Status:** Public pre-alpha research software; not production-authorized.

Skeleton is a portable cognition-kernel research prototype. The public repository contains a reviewed subset of source code, protocol contracts, synthetic fixtures, tests, and public documentation. It is not a full export of the private canonical development repository.

## What is included

- Python reference implementations for evidence, memory, evaluation, bounded learning, and reversible changes.
- JSON Schema contracts and synthetic fixtures.
- Rust contract verification and a Windows foundation-bootstrap package.
- TypeScript contract projections and read-only owner-status tooling.
- Public CI, security documentation, and provenance material.

## What is excluded

Private planning, personal or owner evidence, machine-specific infrastructure, sensitive credentials, historical validation bundles, private knowledge collections, customer data, unreleased capabilities, and separately permissioned organs. Their exclusion is deliberate; do not infer they are publicly reproducible.

## How to evaluate

Review README.md for the exact current MVP status and limitations; PUBLICATION.md describes the clean-history export policy and required release gates. SECURITY-AUDIT.md records a dated, bounded audit, not a perpetual assurance. Check the latest GitHub Actions runs for current test results rather than relying on historical claims.

## Release safety

Do not merge private canonical history into this public mirror. Do not add real credentials, private data, internal plans, binaries or archives without specific redistribution review. Re-run public-readiness, history and tree secret scans, dependency/license checks, clean builds and tests before releasing updates.

**Limitations:** Skeleton has not demonstrated a complete, independently evaluated end-to-end developer agent. It is not a live trading or autonomous execution system.
